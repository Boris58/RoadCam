# RoadCam

Интерактивная карта комплексов фото- и видеофиксации на дорогах России.

## Что уже работает

- карта Пензенской области;
- 127 камер из исходной таблицы;
- поиск по адресу и населённому пункту;
- фильтрация по 22 видам нарушений;
- адаптивный интерфейс для компьютеров и телефонов.

## Обновление камер Пензенской области

Повторяемое обновление из официального Excel запускается сначала без публикации:

```bash
npm run cameras:update-penza -- --input private-data/24.09.2026_Stacionarnye.xlsx --date 2026-09-24
```

Скрипт формирует `data/imports/58/update-report.json` и файл-кандидат. Новый официальный файл считается полной актуальной выборкой стационарных камер: совпавшие записи обновляются с сохранением идентификаторов, новые добавляются, а прежние стационарные камеры, отсутствующие в новом перечне, удаляются. Камеры других типов не затрагиваются. После проверки отчёта публикация выполняется с `--apply`.

## Импорт официальных региональных публикаций

Загрузчик `tools/import-cameras.mjs`:

- открывает страницу региона ГИБДД;
- находит раздел о местах установки средств фотовидеофиксации;
- выбирает последнюю публикацию отдельно для стационарных и передвижных комплексов;
- исключает мобильные комплексы;
- поддерживает XLS/XLSX/ODS, CSV, XML и текстовые PDF;
- сохраняет исходные файлы, нормализованные JSON и `import-report.json`;
- не публикует записи без распознанных и проверенных координат.

Список регионов и официальных страниц хранится в `tools/regions.json`.

Пример проверки списка файлов без скачивания:

```bash
npm run cameras:import -- --region 77 --dry-run
```

Полный импорт Москвы:

```bash
npm run cameras:import -- --region 77
```

Результат сохраняется в `data/imports/77/`. Перед переносом на публичную карту нужно просмотреть `import-report.json` и выборочно проверить координаты.

## Приватная сверка

Закрытый актуальный список можно использовать только для удаления устаревших точек из уже существующей публичной базы. Скрипт не копирует из него адреса, координаты, нарушения или другие поля и не сохраняет его содержимое.

```bash
npm run cameras:reconcile -- \
  --private private-data/current.xlsx \
  --public public/cameras-penza.json
```

Без `--apply` выводится только количество совпадений и предлагаемых удалений. После ручной проверки результат можно сформировать отдельно:

```bash
npm run cameras:reconcile -- \
  --private private-data/current.xlsx \
  --public public/cameras-penza.json \
  --apply \
  --output public/cameras-penza.reconciled.json
```

Папка `private-data/` исключена из истории проекта. Закрытый список нельзя добавлять в репозиторий или размещать на сервере RoadCam.

## Запуск сайта

```bash
npm install
npm run dev
```

## Автоматическое обновление VPS

Проверенный релиз публикуется в `release/gdekamera-release.tar.gz` вместе с SHA-256. На VPS установщик `deploy/install-auto-update.sh` создаёт системный таймер, который примерно раз в час проверяет новый релиз, сверяет контрольную сумму и запускает штатное развёртывание с проверкой и откатом.
